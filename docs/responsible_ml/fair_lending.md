# Fair-lending audit framework

Protected characteristics are prohibited model inputs. Synthetic group labels are audit-only and physically absent from the feature allowlist. Monitoring compares approval rates, risk distributions, default capture, and calibration by group; differences are investigation signals, not proof of discrimination or fairness.

Governance must test proxy effects—including geography—review data quality and reason codes, provide meaningful human review for referrals, control overrides, and monitor policy as well as model outcomes. Technical parity alone is insufficient. Real use requires qualified legal/compliance review, jurisdiction-specific adverse-action procedures, independent validation, documentation, and remediation governance. This project claims none of those approvals.
